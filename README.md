# Launch an Egg

Scripts of the Roblox game [Launch an Egg](https://www.roblox.com/games/128289253725955), synced with [Rojo](https://rojo.space).

Only scripts live here. The map, UI, models and decor stay in the Studio place.

| Folder | In Studio |
| --- | --- |
| `src/server` | ServerScriptService (`Main` + `Server` modules) |
| `src/client` | StarterPlayerScripts (`ClientMain`, `AnimateOthers` + `Client` modules) |
| `src/character` | StarterCharacterScripts (`Animate`) |
| `src/first` | ReplicatedFirst (`LoadingScreen`) |
| `src/shared` | ReplicatedStorage (`PetConfig`, `CharacterAnimator`) |
| `src/tools` | ServerStorage (`Outils`, edit-mode build tools) |

Run `rojo serve`, then connect from the Rojo plugin in Studio.
